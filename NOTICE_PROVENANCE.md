## Supplied starter

The supplied starter provided `TP.qpf`, `TP.qsf`, the SDC and SDRAM PLL, as well as the Nios II/f system, SDRAM controller, JTAG UART, timers, I2C and LEDR PIOs, and on-chip memory. It also supplied the initial VHDL top-level, GPIO I2C wiring and original `hex7seg` function; the reset and exception handlers; timer support; control-register macros; the main loop skeleton; and the Monitor Program project and makefile. Some of these files were subsequently modified as described above.

`I2C_functions.c` and `I2C.h`, including the software I2C primitives, are byte-for-byte identical to the supplied starter. The original contribution uses those primitives in `lire_temperature()`.
